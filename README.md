# Cloud-Diary ☁️

Cloud-Diary is a personal diary web app built with Next.js, Tailwind CSS, Supabase Auth & Postgres RLS, and Jitsi Video Meetings.

## Deployment on Vercel

Set **Root Directory** to `web` during Vercel import or deploy directly.

For full setup documentation, database SQL scripts, and environment variables, see [web/README.md](file:///c:/Users/GOKUL/Downloads/stream/web/README.md).
